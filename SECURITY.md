# Security policy

## Supported versions

Only the `main` branch is supported. Fixes land on `main`; there are no
backported releases.

## Reporting a vulnerability

Please do **not** open a public issue for a vulnerability.

Preferred route: GitHub private vulnerability reporting — open this repo's
**Security** tab, then **Advisories** → **Report a vulnerability**.

If that form is unavailable, open a public issue titled "Security contact
request" with no technical details, and a private channel will be arranged.

This is a personal open-source project maintained in spare time. Expect an
acknowledgement within 7 days. There is no bug bounty.
